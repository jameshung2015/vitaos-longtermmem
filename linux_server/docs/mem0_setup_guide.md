# Mem0 Service Setup Guide (Linux)

This guide explains how to set up and run a self-hosted `mem0` service on your Linux machine. This service will act as a simple API wrapper around the `mem0ai` Python library, providing a persistent memory store for the WeChatMemories project.

The service will expose HTTP endpoints for adding and querying chat log data, and will be accessed by the Langchain agent and the Chatbot backend.

## 1. Prerequisites

*   **Linux System:** A Linux distribution (e.g., Ubuntu, Debian, Fedora).
*   **Python:** Python 3.8 or newer.
*   **Pip:** Python package installer.
*   **Git:** For cloning this project repository (if not already done).
*   **Network Access:** Your Linux machine should be on the same local network as your Windows machine.

## 2. Setup Python Environment

It's highly recommended to use a virtual environment.

```bash
# Navigate to the linux_server directory of this project
# cd /path/to/your/project/linux_server

# Create a virtual environment
python3 -m venv .venv

# Activate the virtual environment
source .venv/bin/activate

# Upgrade pip
pip install --upgrade pip
```

## 3. Install Dependencies

The `mem0` service will require the `mem0ai` library, an API framework (Flask is used in the example below), and potentially a vector database backend supported by `mem0` if not using its default. `lancedb` is a common choice for local persistence with `mem0`. We will also need `gunicorn` for running the Flask app robustly.

Create a `requirements.txt` file in the `linux_server/mem0_service` directory (we will create this directory and the service file next) with the following content:

```txt
# In linux_server/mem0_service/requirements.txt
mem0ai
Flask
gunicorn
lancedb # For local persistent storage with mem0
python-dotenv # To manage environment variables like the shared secret
```

Then, install these dependencies:

```bash
# Ensure your virtual environment is active
# And you are in the linux_server directory or a relevant base for the next paths

# We will create mem0_service directory and the script soon.
# For now, let's assume you'll run pip install from a location
# where it can find this future requirements file, or install manually.

# Example:
# mkdir -p mem0_service
# touch mem0_service/requirements.txt (and paste content above)
# pip install -r mem0_service/requirements.txt
```
*(The actual creation of `mem0_service/requirements.txt` will be done in a subsequent step by the agent)*

For now, you can install them directly if you prefer:
```bash
pip install mem0ai Flask gunicorn lancedb python-dotenv
```

## 4. Create the `mem0` API Service

We will create a simple Flask application to wrap `mem0`.

*   Create a directory for the service: `mkdir -p linux_server/mem0_service`
*   Create a file named `linux_server/mem0_service/app.py` with the Python code for the service (this file will be provided by the development process).
*   Create a `.env` file in `linux_server/mem0_service/` to store the shared secret:
    ```env
    # In linux_server/mem0_service/.env
    SHARED_SECRET_KEY=your_very_secret_and_long_key_here
    MEM0_STORAGE_PATH=./mem0_data # Path for mem0 to store its data
    ```
    **Important:** Replace `your_very_secret_and_long_key_here` with the *actual shared secret key* generated by the Windows Configuration Wizard. The `MEM0_STORAGE_PATH` will be created relative to where `app.py` is run.

The `app.py` will handle:
*   Initializing `mem0.Memory` with a persistent backend (e.g., LanceDB at `MEM0_STORAGE_PATH`).
*   Authentication using the `SHARED_SECRET_KEY`.
*   Endpoints like `/add` (POST) and `/search` (GET/POST).

*(The content of `app.py` will be generated by the AI agent in a following step).*

## 5. Configure and Run the Service with Gunicorn

Gunicorn is a robust WSGI HTTP server for UNIX.

To run the service (once `app.py` is created):

```bash
# Ensure your virtual environment is active
# Navigate to the linux_server/mem0_service directory
cd /path/to/your/project/linux_server/mem0_service

# Run with Gunicorn (example: 2 workers, listening on port 8000 for all interfaces)
gunicorn --workers 2 --bind 0.0.0.0:8000 app:app
```
*   `app:app` refers to the `app` Flask instance within your `app.py` file.
*   `0.0.0.0:8000` makes the service accessible from other machines on your network via your Linux machine's IP address on port 8000.

**Testing:**
Once running, you can test it (e.g., from another terminal on the Linux machine or from Postman/curl on Windows, remembering the shared secret for headers):
```bash
# Example: Test a GET endpoint (actual endpoint TBD)
curl -H "X-Shared-Secret: your_very_secret_and_long_key_here" http://localhost:8000/some_test_endpoint
```

## 6. Ensure Persistent Operation (using `systemd`)

To ensure the `mem0` service starts automatically on boot and restarts if it crashes, you can create a `systemd` service file.

1.  **Create a service file:**
    Open a new file with sudo privileges:
    ```bash
    sudo nano /etc/systemd/system/mem0svc.service
    ```

2.  **Add the following content:**
    Adjust `User`, `Group`, `WorkingDirectory`, `ExecStart`, and `EnvironmentFile` path according to your setup.

    ```ini
    [Unit]
    Description=Mem0 API Service for WeChatMemories
    After=network.target

    [Service]
    User=your_linux_user          # Replace with your actual Linux username
    Group=your_linux_group        # Replace with your actual Linux group (often same as user)
    WorkingDirectory=/path/to/your/project/linux_server/mem0_service # Absolute path
    EnvironmentFile=/path/to/your/project/linux_server/mem0_service/.env # Absolute path to .env

    # Path to gunicorn in your virtual environment
    ExecStart=/path/to/your/project/linux_server/.venv/bin/gunicorn --workers 2 --bind 0.0.0.0:8000 app:app

    Restart=always
    RestartSec=10
    StandardOutput=append:/var/log/mem0svc.log # Optional: Log output
    StandardError=append:/var/log/mem0svc_error.log # Optional: Log errors

    [Install]
    WantedBy=multi-user.target
    ```

    *   **Important:**
        *   Replace `your_linux_user` and `your_linux_group`.
        *   Replace `/path/to/your/project/` with the correct absolute path to your project directory.
        *   Ensure the path to `gunicorn` within your `.venv` is correct.
        *   The `EnvironmentFile` directive loads variables from your `.env` file.

3.  **Reload systemd, enable, and start the service:**
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable mem0svc.service
    sudo systemctl start mem0svc.service
    ```

4.  **Check status:**
    ```bash
    sudo systemctl status mem0svc.service
    journalctl -u mem0svc.service -f # To view logs if configured
    ```

## 7. Firewall Configuration

Ensure your Linux firewall (e.g., `ufw` or `firewalld`) allows incoming connections on port 8000 (or whichever port you configured) from your Windows machine's IP address or your local network.

**Example with `ufw`:**
```bash
sudo ufw allow from <WINDOWS_CLIENT_IP_ADDRESS> to any port 8000 proto tcp comment 'Allow mem0 service from Windows'
# Or, to allow from any IP on the local subnet (e.g., 192.168.1.0/24)
# sudo ufw allow from 192.168.1.0/24 to any port 8000 proto tcp comment 'Allow mem0 service from LAN'
sudo ufw enable # If not already enabled
sudo ufw status
```
Refer to `linux_server/docs/firewall_setup_guide.md` for more general Linux firewall guidance.

This completes the setup for the `mem0` service on your Linux machine. The Windows configuration wizard will generate a config file that the Langchain agent and Chatbot will use to connect to this service and the Ollama service on Windows.
